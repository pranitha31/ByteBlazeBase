College Hub – Club Management System
Project Description
The College Hub – Club Management System is a web-based application designed to simplify the management of college clubs and student activities. 
The system provides a centralized platform where students can explore clubs, register for events, and interact with members, while administrators can manage clubs, events, and notifications.
The platform improves communication, reduces manual work, and increases student engagement by organizing all club-related activities in a single system.


----------
Features

Student registration and login
Club browsing and enrollment
Event creation and management
Event registration for students
Admin approval for events
Notifications and announcements
Club-wise chat system
Password reset via email
Role-based dashboards (Admin, Club Member, Student)
