# 🎓 College Hub – Club Management System

## 📌 Project Description
The **College Hub – Club Management System** is a web-based application designed to simplify the management of college clubs and student activities.  
It provides a centralized platform where:
- 👩‍🎓 Students can explore clubs, register for events, and interact with members.  
- 👨‍💼 Administrators can manage clubs, events, and notifications.  

This system improves communication, reduces manual work, and increases student engagement by organizing all club-related activities in one place.

---

## ✨ Features
- 📝 Student registration and login  
- 🔍 Club browsing and enrollment  
- 🎉 Event creation and management  
- 🎟️ Event registration for students  
- ✅ Admin approval for events  
- 📢 Notifications and announcements  
- 💬 Club-wise chat system  
- 🔑 Password reset via email  
- 📊 Role-based dashboards (Admin, Club Member, Student)

## ⚙️ Setup Instructions
1. Install **XAMPP** and start Apache & MySQL.  
2. Place the project folder inside the `htdocs` directory.  
3. Import the database using **phpMyAdmin**.  
4. Run the project in your browser using:
5. http://localhost/project-folder-name
